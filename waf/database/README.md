Rules:
1. Source code and executable evidence are authoritative.
2. Status text is not evidence.
3. Every phase must record implementation, failures, fixes, tests, measurements and remaining work.
4. Never mark unavailable, unexecuted or unreproduced checks as PASS.
5. Final release requires a 100% gate with zero critical defects.
6. Performance numbers are local measurements unless reproduced in the target environment.
7. Synthetic ML metrics must never be presented as real-world accuracy.
