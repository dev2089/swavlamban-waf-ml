# Phase 10 Final Auditor Checkpoint

This file is the final CI-triggering audit checkpoint for the Phase 10 release candidate.

The independent auditor must treat the GitHub branch `phase10-final` tip containing this file as the immutable source candidate once its CI result is observed. The handoff package generated by the Phase 10 workflow is the transfer artifact for clean-checkout verification.

## Required auditor sequence
1. Verify the exact branch tip SHA and repository state.
2. Inspect `WAF_PROJECT_STATE.json`, `handoff/START_HERE.md`, `handoff/PHASE10_FINAL_STATUS.md`, `handoff/WAF_PHASE10_LOG.md`, the master exam, requirement traceability, production-readiness, security, claim ledger and negative-evidence register.
3. Inspect the complete source tree and the open-source WAF gateway/ModSecurity integration files.
4. Re-run the documented commands from a clean checkout.
5. Treat every builder PASS as untrusted until independently reproduced.

## Evidence classification
Measured evidence, synthetic evaluation, design projections and externally constrained items are explicitly separated in the audit manifest. No secret value belongs in this checkpoint.

## Historical integrity
Known prior defects and remediation history remain in the Phase 1-10 logs. No prior evidence is deleted to improve a score.
