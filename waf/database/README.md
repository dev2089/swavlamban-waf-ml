Evidence rules:
- Source code plus executable results are authoritative.
- A written PASS without an executed check is not evidence.
- Each phase records what changed, what failed, how it was fixed, tests, measurements, limitations and remaining work.
- Final release requires 100% coverage of the project requirements and zero critical defects.
- Local benchmarks are measurements, not production capacity guarantees.
- Synthetic ML metrics are reproducibility evidence, not real-world accuracy claims.
