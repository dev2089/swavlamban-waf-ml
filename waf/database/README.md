# Durable Project Memory

This directory is the durable project memory for future ChatGPT conversations.

Before changing the project, read the latest phase state, independent audit, project journal and future-chat start file.

Current Phase 3 records:
- PHASE_3_STATE.json
- PHASE_3_FEATURE_MANIFEST.json
- PHASE_3_INDEPENDENT_AUDIT.md
- PROJECT_JOURNAL.jsonl
- FUTURE_CHAT_START_HERE.md

Rules:
1. Source code and executable evidence are authoritative.
2. Status text is not evidence.
3. Each phase must record work, failures, fixes, tests and remaining work.
4. Final project release requires a 100% gate and no critical defect.
5. Never turn an unavailable, unexecuted or unreproduced check into PASS.
6. Performance numbers are local evidence unless independently reproduced in the target production environment.
